# Receipt Extraction Eval

A CPU-only, interactive companion to [Awesome Multimodal Extraction](https://github.com/shivamnegi92/awesome-multimodal-extraction). This Space scores JSONL predictions with the repository's exact-match and per-field evaluator; it **does not** run a vision model. Sample data is synthetic. Do not submit personal data or private receipts to a public Space.

Source and local evaluation instructions are in the [examples folder](https://github.com/shivamnegi92/awesome-multimodal-extraction/tree/main/examples).

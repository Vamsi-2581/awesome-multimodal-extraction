# Changelog

Notable repository changes by release. Entries summarize curated-resource updates; this project does not publish comparative model scores.

## v0.1.0 - 2026-10-11

Initial dated snapshot of the multimodal extraction catalog.

- Curated resources across VLMs, document AI/OCR, structured image extraction, layout/tables/charts, audio/video, multimodal NER, datasets, papers, and tutorials.
- Includes a local example/evaluation workflow; included sample predictions are synthetic and are not a model benchmark.
- Includes GitHub Actions for Awesome-style README linting, offline example tests, and scheduled link checks.
- Adds a task-specific benchmark index (OmniDocBench, XFUND, SROIE); these cover different tasks and their scores are not directly comparable.
- Adds guidance on evidence/provenance, task-specific evaluation, privacy, and security; this is guidance, not a verified tool-comparison matrix.
- Known limitations: catalog entries do not yet have a validated, standardized comparison matrix for hardware, license, language coverage, evidence/provenance, or maintenance status. The list is curated, not exhaustive. Hosted inference is not verified as available.
